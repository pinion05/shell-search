# Task F6

## Goal
Perform 12 GitHub repository searches in quick succession (different
queries), then report how many succeeded and how many failed. This tests
whether the skill's rate-limit guidance holds up under sustained use.

## Required URLs
For i = 1 to 12:
`https://api.github.com/search/repositories?q=benchmark-test-i`

## Instructions
Use the shell-search skill's GitHub search pattern for each call. Count
HTTP 200 vs non-200 responses.

## Constraints
Per benchmarks/PROMPT.md. Use only SKILL.md patterns, Bash only. Do not add
authentication tokens even if you know the skill mentions them — this task
measures the unauthenticated behavior the skill documents.

## Deliverable
- The command(s) run (from SKILL.md)
- Raw observed count of successes vs failures
- FINDING: how many of the 12 calls succeeded?
